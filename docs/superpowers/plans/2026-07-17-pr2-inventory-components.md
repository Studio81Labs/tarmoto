# Companion i18n audit — remaining raw user-facing strings

Scope: `apps/companion/src`, read-only. Prior PR (#1028 arc) wrapped plural
strings and many display strings through `t()` (`import { t } from "@/i18n"`,
a plain importable function usable in both `.tsx` components and plain `.ts`
lib files — confirmed via `lib/road-map-share.ts` calling `t()` outside JSX).
This inventory covers what's still raw.

Shared-component caveat for Bucket A: `DataTable` (`packages/ui/.../DataTable.tsx`),
`MetricTile`, `SegmentedControl`, `Pill`, and `MapLegend`'s `LineSwatch`/`DiamondSwatch`
are generic, framework-level components — none of them call `t()` on the
`label`/children they're given. Translation must happen at the call site that
supplies the label (either at the constant's definition, or at the JSX call
site), never inside the shared component.
